## มีอะไรใหม่ใน 1.3.6

- **Full Agent คุม browser ได้จริง** — inspect / คลิก / พิมพ์ / เลือก dropdown / กดปุ่มคีย์ / scroll / wait
  ช่อง password แอปจะไม่พิมพ์แทน ให้ผู้ใช้พิมพ์เองเพื่อความปลอดภัย
- แก้ปุ่ม "ย้อนรันเบื้องหลัง" ให้กลับไปหน้าที่เปิด Full Agent มา ไม่เด้งไปหน้าบันทึกงาน
- แก้บั๊กพอร์ตชน ตอนเปิดแอปมากกว่าหนึ่ง instance
- ตัวติดตั้งสะอาด — ใส่เฉพาะข้อมูลตัวอย่าง ไม่มีข้อมูลผู้ใช้ใด ๆ ติดไป

## วิธีติดตั้ง

1. เปิดไฟล์ `.dmg` แล้วลากแอปไป `Applications`
2. เปิดครั้งแรกถ้า macOS ถามเรื่อความปลอดภัย: คลิกขวาที่แอป → **Open** → **Open**
3. ต้องใช้ macOS บนชิป Apple Silicon (arm64)
